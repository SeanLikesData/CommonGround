# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

### Full stack (Docker)
```bash
docker compose up            # start all services
docker compose up --watch    # start with frontend hot-reload sync
docker compose up <service>  # start a single service (e.g. api, agent, frontend)
docker compose build         # rebuild images after dependency changes
```

### Frontend (local dev, inside `frontend/`)
```bash
npm run dev    # Vite dev server on :3000
npm run build  # TypeScript check + Vite build
npm run lint   # ESLint
```

The frontend uses **pnpm** (v9.15.9) as its package manager — use `pnpm` instead of `npm` when installing packages.

## Environment variables

Create a `.env` file at the repo root before running `docker compose`:

```
ANTHROPIC_API_KEY=...          # required by agent, report-gen, kg-update
NEO4J_PASSWORD=...             # required by agent, kg-update, neo4j
VITE_MAPTILER_KEY=...          # MapTiler API key for the map tiles
OPENAI_API_KEY=...             # used by kg-update (Graphiti)

# Optional overrides
VITE_API_URL=http://localhost:8000
VITE_AGENT_URL=http://localhost:8001
AGENT_MODEL=anthropic:claude-haiku-4-5
AGENT_INTERVAL_SEC=15
AGENT_RECENT_WINDOW_SEC=900
AGENT_BASELINE_WINDOW_SEC=86400
```

Frontend secrets go in `frontend/.env.local` (Vite exposes only `VITE_`-prefixed vars to the client).

## Architecture

CommonGround is a **battlespace intelligence analysis system** composed of six services orchestrated by Docker Compose, two data stores, and a React SPA.

### Data flow

```
data-streaming ──► MongoDB (signals) ──► report-gen ──► MongoDB (reports)
                                                              │
                                                         kg-update ──► Neo4j (knowledge graph)
                                                                            │
                                           api (MongoDB, read-only) ◄──────┤
                                           agent (Neo4j, heuristics) ◄─────┘
                                                    │
                                               frontend (React SPA)
```

1. **data-streaming** emits synthetic sensor signals (RF, drone_video, UGS) into MongoDB, driven by scenario scripts (`data-streaming/scenarios/`) with fallback background noise.
2. **report-gen** polls new signals, applies a confidence threshold, and writes SPOT/SALUTE-format reports back to MongoDB.
3. **kg-update** polls new reports and syncs them into Neo4j via [Graphiti](https://github.com/getzep/graphiti) (AI-assisted knowledge graph enrichment). Requires both `ANTHROPIC_API_KEY` and `OPENAI_API_KEY`.
4. **api** is a read-only FastAPI service on `:8000` — GET-only routes for `/signals`, `/reports`, `/health`. Results are sorted by `signal.timestamp` descending.
5. **agent** runs on `:8001` with two responsibilities:
   - A background loop (APScheduler, every `AGENT_INTERVAL_SEC`) that executes 8 Neo4j Cypher heuristics (`agent/graph.py`), feeds results to a PydanticAI agent (`agent/agent.py`), and writes a sitrep summary to `agent/memories.md` (persisted via Docker volume).
   - A `/ask` FastAPI endpoint (`agent/server.py`) that exposes a QA agent with three tools: `cypher_query` (read-only Neo4j), `mongo_read`, and `remember` (reads/updates `memories.md`).
6. **frontend** is a React 19 + Vite SPA on `:3000` with a MapLibre GL map, signal/alert feed panels, and a chat panel wired to the `/ask` endpoint.

### Intelligence heuristics (agent/graph.py)

Eight Cypher-based patterns drive the agent's analysis: `new_activity`, `multi_int_corroboration`, `first_contact`, `force_concentration`, `modality_shift`, `persistent_contact`, `sensor_reactivation`, and a compound pattern. Triggered within configurable time windows (`AGENT_RECENT_WINDOW_SEC`, `AGENT_BASELINE_WINDOW_SEC`).

### Frontend state & components

- **Zustand** manages global state; stores live in `frontend/src/lib/`.
- Path alias `@/` maps to `frontend/src/`.
- Key components: `MapCanvas` (MapLibre), `SpotFeed`, `AlertFeed`, `AgentPanel` (chat), `LeftPanel`, `NavRail`.
- Tailwind v4 is configured via `@tailwindcss/vite` — no separate PostCSS config needed.

### Data schemas

- **Signal**: sensor type, confidence, geohash, timestamp, raw payload.
- **SPOT/SALUTE report**: Size, Activity, Location (lat/lon + geohash), Unit, Time, Equipment — generated by `report-gen/report.py` using Claude.
- **Neo4j nodes**: `SpotReport` nodes with SALUTE fields; relationships built by Graphiti.
